## Мета

Зробити «Рахунок постачальника» повністю робочим і придатним для оцінки — і для **реальних ролей**, і для **тестових ролей через «жука»**. Адмін відкриває рахунок кожного магазину зі свого блоку магазинів; постачальник керує своїми коштами (з окремою кнопкою автооплат); менеджер бачить лише статуси оплат замовлень без доступу до коштів.

## Чому зараз «не активний для перегляду»

1. Бекенд `bank-gateway` читає **справжню** роль користувача з бази. Коли адмін через «жука» перемикається на постачальника/менеджера, запити все одно йдуть як `admin` (`staff`), тож перемикач ролі не змінює вміст рахунку.
2. Тестових даних майже немає (3 баланси, 4 рухи, 0 карток), тому рахунки виглядають порожніми.

## Що буде зроблено

### 1. Підтримка тестових ролей у рахунку (головне)
- Фронтенд передає у `bank-gateway` поточну ефективну роль з «жука» (`preview_role`) в діях балансу.
- Бекенд поважає `preview_role` **лише коли справжній користувач — адмін** (пониження прав, ніколи не підвищення):
  - `supplier` → всі магазини трактуються як «власник» (повний доступ, керування коштами);
  - `shop_manager` → всі магазини як «менеджер» (лише перегляд статусів оплат);
  - `moderator` → перегляд балансів без керування.
- Це дає змогу натиснути «жука» і побачити рахунок очима кожної ролі на тих самих тестових даних.

### 2. Кнопка «Рахунок» у блоці магазинів адміна
- Кнопка вже є біля кожного магазину; переконаємось, що вона відкриває заповнений рахунок обраного магазину (`/supplier-balance/:id`) з балансом, статистикою та рухом коштів.

### 3. Окрема кнопка «Автооплати» (для власника)
- У `SupplierBalanceCard` додається окрема кнопка **«Автооплати»**, що відкриває окремий діалог налаштувань:
  - авто-вивід доступних коштів,
  - авто-списання нашої націнки з картки (наложені),
  - мінімальна сума виводу,
  - прив'язка/зміна картки.
- Перемикачі авто-режимів переносяться з основної картки в цей діалог, щоб інтерфейс був чистішим.

### 4. Перегляд оплат менеджером (без коштів)
- Для ролі `manager` замість картки балансу показується панель **«Оплати замовлень»**: список замовлень магазину зі статусами оплати — **Створено / Часткова / Оплачено** — без сум балансу, виплат чи карток.
- Нова серверна дія `list_shop_payments` повертає статуси оплат замовлень (з `order_splits`); доступна власнику, менеджеру та staff.

### 5. Тестові дані для всіх тестових магазинів
- Розширюється `seed-test-payments`, щоб заповнити **всі** тестові магазини:
  - `shop_balances` (доступно / в обробці / всього виплачено),
  - `balance_movements` усіх типів (нарахування, націнка, вивід, списання, повернення),
  - `order_splits` у трьох стадіях (створено / в обробці / оплачено) з розкладкою по днях/тижнях/місяцях/роках,
  - `payout_methods` з демо-картками (для показу автооплат),
  - `shop_manager_links`, щоб можна було перевірити режим менеджера.

## Технічні деталі

- **`supabase/functions/bank-gateway/index.ts`**: додати обробку `preview_role` у `getShopAccess`, `list_my_shops`, `get_balance`, `get_stats`; додати дію `list_shop_payments`. Пониження прав тільки для реальних адмінів.
- **`src/components/supplier/SupplierBalanceCard.tsx`**: винести авто-налаштування в окремий діалог «Автооплати»; передавати `preview_role`.
- **`src/pages/SupplierBalance.tsx`**: для менеджера рендерити панель статусів оплат замість картки коштів; передавати `preview_role` в усі виклики.
- **Новий** `src/components/supplier/ShopPaymentsView.tsx`: список замовлень зі статусами оплати для менеджера.
- **`supabase/functions/seed-test-payments/index.ts`**: генерація повної історії для всіх тестових магазинів.
- **`src/components/admin/AdminStoreManager.tsx`**: перевірка кнопки «Рахунок» біля кожного магазину.

## Перевірка

- `curl`/invoke `bank-gateway` з `preview_role` = supplier / shop_manager / moderator → різні рівні доступу на однакових даних.
- Playwright: адмін → блок магазинів → «Рахунок» відкриває заповнений рахунок; «жук» → supplier бачить кошти + автооплати; «жук» → shop_manager бачить лише статуси оплат.
- Чистий білд.

Реальні перекази лишаються в режимі sandbox, доки не додано ключі банку — це окремий крок за твоїм сигналом.
